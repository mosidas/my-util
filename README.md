# my-util

コマンドラインのユーティリティ集。

- `util pass`: パスワードを生成する
- `util zip`: ディレクトリの直下のフォルダーを、フォルダーごとに zip に圧縮する

## インストール

配布物は無い。ソースからインストールする。

1. Go 1.23 以上をインストールする。
2. リポジトリをクローンする。
3. リポジトリのルートで `go install` を実行する。`go env GOPATH` が示すディレクトリの `bin` に `util` ができる。`GOBIN` を設定しているときは `GOBIN` にできる。
4. `util --help` を実行する。

## 使い方

```sh
util pass -l 12
```

## 開発

テストは次のコマンドで実行する。

```sh
go test ./...
```
