# my-util

パスワードの生成と、フォルダーの一括圧縮を行うコマンドラインツール。

## インストール

配布物は無い。ソースからインストールする。

1. Go 1.23 以上をインストールする。
2. リポジトリをクローンする。
3. リポジトリのルートで `go install` を実行する。`$GOBIN`(既定は `~/go/bin`)に `util` ができる。
4. `util --help` を実行する。

## 使い方

```sh
util pass -l 12
```

12 文字のパスワードが標準出力に出る。

フォルダーをまとめて圧縮するには、[my-util のコマンド](docs/commands.md) の `zip` を実行する。

## 開発

道具は「インストール」の 1. と同じである。テストは次のコマンドで実行する。

```sh
go test ./...
```
