# my-util のコマンド

`util` のサブコマンドごとに、オプション・既定値・挙動を一覧にする。インストールは [my-util の README](../README.md) の手順で行う。

## pass

パスワードを 1 つ生成し、標準出力に出す。

| オプション | 内容 | 既定値 |
| :- | :- | :- |
| `-l`, `--length` | パスワードの長さ。8 以上を指定する | 8 |
| `-p`, `--policy` | 使う文字種。`all` か `alphanum` を指定する | `all` |

ポリシーごとに、次の文字種をそれぞれ 1 文字以上含める。

| ポリシー | 大文字(A-Z) | 小文字(a-z) | 数字(0-9) | 記号 |
| :- | :- | :- | :- | :- |
| `all` | 含める | 含める | 含める | 含める |
| `alphanum` | 含める | 含める | 含める | - |

記号は ``!#$%&()*+,-./:;<=>?@[]^_`{|}~`` である。

```sh
util pass                    # 8 文字、すべての文字種
util pass -l 12              # 12 文字
util pass -l 16 -p alphanum  # 16 文字、英数字
```

## zip

対象のディレクトリの直下にある各フォルダーを、それぞれ `<フォルダー名>.zip` に圧縮する。zip ファイルは対象のディレクトリの直下に作成する。対象のディレクトリを省略したときは、カレントディレクトリを `<カレントディレクトリ名>.zip` に圧縮する。

| オプション | 内容 |
| :- | :- |
| `-y`, `--yes` | 確認のプロンプトを表示せずに実行する |

- 圧縮の前に、確認のプロンプト(y/n)を表示する。
- 隠しフォルダー(`.` で始まるフォルダー)は圧縮しない。
- `.DS_Store` ファイルと `__MACOSX` ディレクトリは zip に含めない。

```sh
util zip ~/Documents/my_folders     # 直下の各フォルダーを個別に圧縮する
util zip                            # カレントディレクトリを圧縮する
util zip -y ~/Documents/my_folders  # 確認のプロンプトを表示しない
```
